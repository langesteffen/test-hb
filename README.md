# GitHub Pages Testprojekt

Dieses Repository dient zum Ausprobieren von **GitHub Pages**.  
Die Startseite wird aus der Datei `index.md` generiert.

## Inhalt

- `index.md` – Hauptseite der Website
- `README.md` – kurze Erklärung zum Projekt

## GitHub Pages aktivieren

1. Dieses Repository zu GitHub pushen  
2. Auf GitHub ins Repository gehen  
3. **Settings** → **Pages** auswählen  
4. Unter **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: z. B. `main` und Ordner `/ (root)` auswählen
5. Speichern – nach kurzer Zeit ist die Seite online

Die URL sieht ungefähr so aus:

```text
https://<dein-github-username>.github.io/<repository-name>/
